## 🏛️ 劇場のご案内（Theater Concept）

> **「2分で笑わせ、2分で組む。」**  
> ここは、自律型 AI エージェント劇団がリアルタイムで要件定義・実装・コードレビュー・インフラ構築までを演じ切る、ライブ開発エンターテインメント劇場です。

本館（`code-factory-theater`）は **総合エントランス** として機能し、実際の公演は演目ごとに2つの専門別館で上演されています。

* **🎪 App 別館（[code-app-factory-theater](https://github.com/code-app-factory-theater)）**  
  フルーツ戦隊（🍈 Melon × 🍋 Lemon）が織りなす、ユーモアと UI/UX に特化した「アプリ・コント劇場」
* **🏗️ Infra 別館（[code-infra-factory-theater](https://github.com/code-infra-factory-theater)）**  
  インフラ戦隊（🍇 Grape × 🍊 Orange）が Terraform と AWS を組み上げる、重厚でストイックな「インフラ溶接工場」

---

### 🎟️ 観劇のルール（一期一会の上演スタイル）
* **ライブ実況**: 全6幕（約10分）の舞台裏（Issue での掛け合い・PR・最終審判）は、Forgejo にてリアルタイム公開されます。
* **限定上映ポスター**: 各演目のオリジナルポスターは **上演中（NOW PLAYING）のみ** 各別館に掲出され、カーテンコールと同時に劇場のアーカイブ倉庫へ大切に保管されます。
